# ACX security model
Treat all manifests as untrusted until origin and signature policy are satisfied. Agents must not infer missing permissions. Consequential and critical actions require preflight. Commit requests must bind to a preflight/request digest. Credentials should be audience-, scope-, and time-limited. Receipts must not leak secrets. Redirects and remote schema references require SSRF protections. Providers must defend against replay, confused-deputy attacks, capability squatting, schema substitution, price changes after authorization, and TOCTOU changes between preflight and commit.
